## 🛠️ Tech Stack

- React 19 + TypeScript 5
- Vite 6 + Tailwind CSS v4
- Vitest + React Testing Library

## 🏁 Quick Start

```bash
git clone https://github.com/mk-knight23/18-web-atmospheric-dashboard.git
cd 18-web-atmospheric-dashboard
npm install
npm run dev
```

## 🧪 Testing
