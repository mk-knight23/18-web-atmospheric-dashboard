# MK SkyPulse

**Weather & Activity Planning Dashboard**

Current weather, forecasts, saved locations, and activity planner.

🔗 **Live**: [https://18-web-atmospheric-dashboard.vercel.app](https://18-web-atmospheric-dashboard.vercel.app)

## Tech Stack

Angular 21, TypeScript, Tailwind CSS 4, OpenWeatherMap API

## Getting Started

```bash
npm install
npm run dev
```
